# The God of Rage

You are Mwanafyale.
You are very strong.
Bad monsters come. Hit them.
The storm comes too. Stay inside the ring.

**Three ways to play**

- **Storm Co-op.** Fight the waves together. Pull fallen friends back up.
- **Storm Duel.** Everyone fights everyone. First to three rounds wins.
- **Altar Siege.** Two tribes fight for the centre altar. First to three captures wins.

No one else online? Start any mode alone. Duel and Siege give you a solo hunt
against the storm until a rival arrives.

**How to play**

<div align="center">

| Do this | Press |
|---|---|
| Walk | `W` `A` `S` `D` |
| Hit | Left mouse / `Space` |
| Change weapon | `E` |
| Rage | `Q` |
| Stop | `P` |
| Talk | `Enter` |
| Help | `H` |

</div>

Hit three times with the chain.
Whoosh. The chain flies out.
It hits very hard. Then it comes back.
